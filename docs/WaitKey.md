# 等待按键触发 (WaitKey)

暂停流程，直到用户按下了键盘上的某个指定按键后再继续。

## 平台与权限

* **支持平台**: `跨平台 (Windows / Linux / macOS)`
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **目标按键 (`key`)**
  * 类型: `KeySequence`
  * 默认值: `"Enter"`
  * 描述: 按键名称或组合键。常用预设：`Enter`, `Escape`, `Space`, `F1`, `F2`。
* **超时时间 (秒) (`timeout`)**
  * 类型: `real`
  * 默认值: `5.0`
  * 描述: 等待超时时间（秒），0 表示无限等待。常用预设：`1.0`, `3.0`, `5.0`, `0.0`。

## 输出

* 类型: `bool`
* 描述: 按键捕获状态。在超时时限内检测到目标按键按下返回 `true`，超时未触发返回 `false`。

## 使用示例

```json
{
    "tag": "WaitKey",
    "key": "Enter",
    "timeout": 5.0
}
```
