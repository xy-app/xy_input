# 等待按键触发 (WaitKey)

暂停流程，直到用户按下了键盘上的某个指定按键后再继续

## 运行参数

* **目标按键 (`key`)**
  * 类型: `KeySequence`
  * 默认值: `"Enter"`
  * 描述: 按键名称或组合键。常用预设：`Enter`, `Escape`, `Space`, `F1`, `F2`。
* **超时时间 (秒) (`timeout`)**
  * 类型: `real`
  * 默认值: `"5.0"`
  * 描述: 等待超时时间(秒)，0表示无限等待。常用预设：`1.0`, `3.0`, `5.0`, `0.0`。

## 输出

* 类型: `bool`
* 描述: 等待特定按键触发状态 (true 表示成功捕获或未超时)。

## 使用示例

```json
{
    "tag":  "WaitKey",
    "key":  "Enter",
    "timeout":  "5.0"
}
```
