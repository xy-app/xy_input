# 光标坐标 (PointerPosition)

获取当前鼠标光标物理坐标位置，或将光标瞬移至指定坐标。

## 平台与权限

* **支持平台**: `跨平台 (Windows / Linux / macOS)`
* **权限要求**: 普通用户权限（无需管理员提权）

## 运行参数

* **操作模式 (`action`)**
  * 类型: `string`
  * 默认值: `"Get"`
  * 描述: 操作模式。常用预设：`Get` (获取当前坐标), `Set` (瞬移到指定坐标)。
* **目标坐标 (`xy`)**
  * 类型: `Point`
  * 默认值: `"0,0"`
  * 描述: 目标瞬移坐标 (仅在 action 为 Set 时生效)。常用预设：`0,0`, `100,100`, `500,500`。
* **驱动模式 (`driver`)**
  * 类型: `driver`
  * 默认值: `"Default"`
  * 描述: 输入驱动模式。常用预设：`Default`, `System`, `KMBox`。
    - Default: 全局硬件优先；若已连接 KMBox 则走硬件，未连接则降级系统软件模拟。
    - System: 强制系统底层模拟。
    - KMBox: 强制硬件盒子。

## 输出

* 类型: `Point`
* 描述: 鼠标光标物理屏幕坐标点 `(X, Y)`。在 Get 模式下返回当前实际光标位置；在 Set 模式下返回瞬移后的目标坐标。

## 使用示例

```json
{
    "tag": "PointerPosition",
    "action": "Get",
    "xy": "0,0",
    "driver": "Default"
}
```
