# 移动鼠标 (MovePointer)

将鼠标光标移动到屏幕上的指定像素位置或按相对偏移量移动。

## 平台与权限

* **支持平台**: `跨平台 (Windows / Linux / macOS)`
* **权限要求**: 普通用户权限（无需管理员提权；若目标程序具有管理员UIPI权限需同等权限）

## 运行参数

* **目标坐标/偏移量 (`xy`)**
  * 类型: `Point`
  * 默认值: `"100,100"`
  * 描述: 目标绝对屏幕坐标或相对位移量 (X, Y)。常用预设：`100,100`, `500,500`, `10,0`, `0,10`, `-10,0`, `0,-10`。
* **移动模式 (`mode`)**
  * 类型: `string`
  * 默认值: `"Absolute"`
  * 描述: 坐标基准模式。常用预设：`Absolute` (绝对像素坐标), `Relative` (相对当前光标位置偏移)。
* **驱动选择 (`driver`)**
  * 类型: `driver`
  * 默认值: `"Default"`
  * 描述: 输入驱动模式。常用预设：`Default`, `System`, `KMBox`。
    - Default: 全局硬件优先；若已连接 KMBox 则走硬件，未连接则降级系统软件模拟。
    - System: 强制系统底层模拟。
    - KMBox: 强制硬件盒子，未连则报错。

## 输出

* 类型: `bool`
* 描述: 鼠标光标移动执行状态。成功移动到目标坐标返回 `true`，失败返回 `false`。

## 使用示例

```json
{
    "tag": "MovePointer",
    "xy": "100,100",
    "mode": "Absolute",
    "driver": "Default"
}
```
