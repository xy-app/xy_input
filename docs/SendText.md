# 模拟文本输入 (SendText)

向当前的输入框模拟敲击键盘输入一段文本内容

## 运行参数

* **输入文本内容 (`text`)**
  * 类型: `string`
  * 默认值: `""`
  * 描述: 要输入的文本。
* **输入后自动回车 (`enter_key`)**
  * 类型: `bool`
  * 默认值: `false`
  * 描述: 输入完成是否附带敲击回车键。常用预设：`true`, `false`。

## 输出

* 类型: `bool`
* 描述: 文本字符串键入完成状态 (true 表示成功)。

## 使用示例

```json
{
    "tag":  "SendText",
    "text":  "",
    "enter_key":  false
}
```
