# 鼠标点击 (Click)

在当前鼠标所在位置或屏幕指定坐标上单击或双击鼠标

## 运行参数

* **鼠标按键 (`button`)**
  * 类型: `string`
  * 默认值: `"left"`
  * 描述: 触发的鼠标键位。常用预设：`left`, `right`, `middle`。
* **点击次数 (`times`)**
  * 类型: `number`
  * 默认值: `1`
  * 描述: 连续点击次数。常用预设：`1`, `2`。
* **点击间隔 (毫秒) (`interval`)**
  * 类型: `number`
  * 默认值: `50`
  * 描述: 连续点击间隔。常用预设：`50`, `100`。

## 输出

* 类型: `bool`
* 描述: 鼠标点击操作执行状态 (true 表示成功)。

## 使用示例

```json
{
    "tag":  "Click",
    "button":  "left",
    "times":  1,
    "interval":  50
}
```
