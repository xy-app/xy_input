# 滚动鼠标滚轮 (WheelMouse)

模拟鼠标滚轮向上或向下滚动指定步数，常用于网页或文档翻页

## 运行参数

* **滚动方向 (`direction`)**
  * 类型: `string`
  * 默认值: `"down"`
  * 描述: 滚轮转动方向。常用预设：`up`, `down`。
* **滚动格数 (`times`)**
  * 类型: `number`
  * 默认值: `3`
  * 描述: 滚轮转动的刻度格数。常用预设：`1`, `3`, `5`, `10`。
* **每次间隔 (毫秒) (`interval`)**
  * 类型: `number`
  * 默认值: `50`
  * 描述: 多次滚动间的间隔时间。常用预设：`20`, `50`, `100`。

## 输出

* 类型: `bool`
* 描述: 鼠标滚轮滚动执行状态 (true 表示成功)。

## 使用示例

```json
{
    "tag":  "WheelMouse",
    "direction":  "down",
    "times":  3,
    "interval":  50
}
```
