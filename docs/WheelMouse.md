# 滚动鼠标滚轮 (WheelMouse)

模拟鼠标滚轮向上或向下滚动指定步数，常用于网页或文档翻页。

## 平台与权限

* **支持平台**: `跨平台 (Windows / Linux / macOS)`
* **权限要求**: 普通用户权限（无需管理员提权；若受控程序拥有管理员UIPI权限需同等权限）

## 运行参数

* **滚动方向 (`direction`)**
  * 类型: `string`
  * 默认值: `"down"`
  * 描述: 滚轮转动方向。常用预设：`up`, `down`。
* **滚动格数 (`times`)**
  * 类型: `number`
  * 默认值: `3`
  * 描述: 滚轮转动的刻度格数。常用预设：`1`, `3`, `5`, `10`。
* **每次间隔 (毫秒) (`interval`)**
  * 类型: `number`
  * 默认值: `50`
  * 描述: 多次滚动间的间隔时间（毫秒）。常用预设：`20`, `50`, `100`。
* **驱动选择 (`driver`)**
  * 类型: `driver`
  * 默认值: `"Default"`
  * 描述: 输入驱动模式。常用预设：`Default`, `System`, `KMBox`。
    - Default: 全局硬件优先；若已连接 KMBox 则走硬件，未连接则降级系统软件模拟。
    - System: 强制使用操作系统原生底层 API 模拟。
    - KMBox: 强制使用 KMBox 物理硬件外设；若未连接则直接报错中断。

## 输出

* 类型: `bool`
* 描述: 鼠标滚轮滚动执行状态。成功发送滚动刻度序列返回 `true`，失败返回 `false`。

## 使用示例

```json
{
    "tag": "WheelMouse",
    "direction": "down",
    "times": 3,
    "interval": 50,
    "driver": "Default"
}
```
