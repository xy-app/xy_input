# 单元格点击 (CellsClick)

在指定的网格或单元格矩形坐标区域自动均匀划分并依次执行鼠标点击，适用于九宫格、棋盘格、批量列表项的批量遍历点击。

## 平台与权限

* **支持平台**: `跨平台 (Windows / Linux / macOS)`
* **权限要求**: 普通用户权限（无需管理员提权；若目标程序具有管理员UIPI权限需同等权限）

## 运行参数

* **目标网格区域 (`target`)**
  * 类型: `Rect`
  * 默认值: `"0, 0, 0, 0"`
  * 描述: 目标屏幕网格矩形区域 (x, y, width, height)。常用预设：`0, 0, 1920, 1080`, `100, 100, 800, 600`。
* **网格行列数 (`grid`)**
  * 类型: `Size`
  * 默认值: `"3, 3"`
  * 描述: 划分网格的列数与行数 (如 3, 3 为九宫格)。常用预设：`3, 3`, `4, 6`, `12, 12`。
* **点击间隔延时 (秒) (`delay`)**
  * 类型: `real`
  * 默认值: `0.05`
  * 描述: 依次点击每个单元格之间的间隔延迟时间（秒）。常用预设：`0.05`, `0.1`, `0.2`。
* **鼠标按键 (`button`)**
  * 类型: `MouseButton`
  * 默认值: `"Left"`
  * 描述: 触发点击的鼠标键位。常用预设：`Left`, `Right`, `Middle`。
* **驱动选择 (`driver`)**
  * 类型: `driver`
  * 默认值: `"Default"`
  * 描述: 输入驱动模式。常用预设：`Default`, `System`, `KMBox`。
    - Default: 全局硬件优先；若已连接 KMBox 则走硬件，未连接则降级系统软件模拟。
    - System: 强制使用操作系统原生底层 API 模拟。
    - KMBox: 强制使用 KMBox 物理硬件外设；若未连接则直接报错中断。

## 输出

* 类型: `bool`
* 描述: 单元格批量点击全部完成状态。执行成功返回 `true`；若中断或参数异常返回 `false`。

## 使用示例

```json
{
    "tag": "CellsClick",
    "target": "100, 100, 600, 600",
    "grid": "3, 3",
    "delay": 0.05,
    "button": "Left",
    "driver": "Default"
}
```
