# 单元格点击 (CellsClick)

在指定的网格或单元格坐标区域自动执行鼠标点击

## 运行参数

* **目标网格区域 (`target`)**
  * 类型: `Rect`
  * 默认值: `"0, 0, 0, 0"`
  * 描述: 目标屏幕网格矩形区域 (x, y, width, height)。常用预设：`0, 0, 1920, 1080`, `100, 100, 800, 600`。
* **网格行列数 (`grid`)**
  * 类型: `Size`
  * 默认值: `"3, 3"`
  * 描述: 划分网格的列数与行数 (如 3, 3)。常用预设：`3, 3`, `4, 6`, `12, 12`。
* **点击间隔延时 (秒) (`delay`)**
  * 类型: `Real`
  * 默认值: `"0.05"`
  * 描述: 依次点击每个单元格之间的间隔延迟时间 (秒)。常用预设：`0.05`, `0.1`, `0.2`。
* **鼠标按键 (`button`)**
  * 类型: `MouseButton`
  * 默认值: `"Left"`
  * 描述: 触发点击的鼠标键位。常用预设：`Left`, `Right`, `Middle`, `DoubleClick`, `None`。

## 输出

* 类型: `bool`
* 描述: 单元格点击批处理执行状态 (true 表示成功)。

## 使用示例

```json
{
    "tag":  "CellsClick",
    "target":  "0, 0, 0, 0",
    "grid":  "3, 3",
    "delay":  "0.05",
    "button":  "Left"
}
```
