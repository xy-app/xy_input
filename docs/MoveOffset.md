# 鼠标相对偏移移动 (MoveOffset)

让鼠标光标相对于当前位置向上、下、左、右移动指定距离

## 运行参数

* **偏移量 (X, Y) (`offset`)**
  * 类型: `string`
  * 默认值: `"10,0"`
  * 描述: 相对当前坐标的偏移像素。常用预设：`10,0`, `0,10`, `-10,0`, `0,-10`。

## 输出

* 类型: `bool`
* 描述: 鼠标相对位移执行状态 (true 表示成功)。

## 使用示例

```json
{
    "tag":  "MoveOffset",
    "offset":  "10,0"
}
```
