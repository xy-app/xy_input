# 鼠标拖拽 (DragPointer)

按住鼠标从当前位置平滑拖拽移动到目标位置，常用于滑块滑动或拖动文件

## 运行参数

* **拖拽按键 (`button`)**
  * 类型: `string`
  * 默认值: `"left"`
  * 描述: 拖拽过程中按住的鼠标键。常用预设：`left`, `right`。
* **偏移坐标 (X, Y) (`offset`)**
  * 类型: `string`
  * 默认值: `"100,0"`
  * 描述: 相对当前光标位置的偏移量。常用预设：`100,0`, `0,100`, `100,100`。
* **拖拽持续时间 (毫秒) (`duration`)**
  * 类型: `number`
  * 默认值: `200`
  * 描述: 平滑移动耗时。常用预设：`100`, `200`, `500`。

## 输出

* 类型: `bool`
* 描述: 鼠标拖拽滑动执行状态 (true 表示成功)。

## 使用示例

```json
{
    "tag":  "DragPointer",
    "button":  "left",
    "offset":  "100,0",
    "duration":  200
}
```
